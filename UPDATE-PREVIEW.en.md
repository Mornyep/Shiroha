# Next up: a shorter route to the title screen

You came to pick a heroine's route, not an executable's path. The next Shiroha update is about trimming the setup chapter.

Here's what's being worked on:

- **Less setup déjà vu:** tidier CrossOver defaults and runtime-provider settings, with fewer repeated choices.
- **The right game, please:** better Bangumi and VNDB entry and rating matching. Picking the wrong route is one thing; attaching another game's details is another.
- **Favorites that stay together:** improvements to linked favorites and simpler poster color settings. Unused wallpaper and disc-art options are being removed; existing images and shared color extraction stay.
- **Playtime with a source:** Steam playtime import from JSON and local timing. This means importing a file, not signing into Steam for automatic sync.

These are still candidate-build features. UI workflows and timing in real games need verification. **The available download is still the [v0.14.0 public preview](https://github.com/Mornyep/Shiroha/releases/tag/v0.14.0).** No release date yet. Let's not tempt the “announced too early” ending.

Route and save recognition is also being explored, starting with restricted Ren'Py scripts, original sample saves, and limited path analysis. It cannot currently identify commercial-game endings or follow the story live, and it does not offer general save support. Keep saving before choices. Shiroha can't reload that decision for you.

Windows games still primarily run through CrossOver. GalBridge's independent compatibility approach remains experimental, with no verified commercial-game support list. The library, launcher, and local diagnostics don't need an AI account. AI summary explanations are optional, and you can preview the content before sending it.

Chinese, English, Japanese, and Korean documentation is available for installation and feedback. These are documentation languages; the app interface remains primarily Chinese.

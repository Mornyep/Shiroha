## 0.14.0 · Public preview

- Added multiple named bookmarks, manual guide steps, prerequisites, and completion status.
- Added external Steam library discovery, launch log management, and VNDB Steam App ID lookup.
- Improved detail, settings, and editing views, including long titles, long descriptions, and keyboard focus after returning.
- Fixed backup verification, bookmark migration, stale scan results, configuration overwrites, and guide-editing conflicts.
- Renamed the app to “白羽 Shiroha” and added a new icon, while retaining the existing data directory and internal identifiers.
- Added icon generation and removed build-machine paths from distribution packages.

For downloads, requirements, and known limits, see the [release notes](RELEASE-NOTES.en.md).
